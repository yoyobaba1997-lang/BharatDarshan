# Content and Source Policy

BharatDarshan provides catalogue metadata and discovery functionality. It must not host, copy, or redistribute copyrighted video/audio without permission. Integrations must use authorized providers, official APIs, or user-owned media sources and respect terms, access controls, and applicable law.

Anime and dubbed-language metadata are supported as catalogue classifications. The project will not include piracy link lists, DRM circumvention, credential theft, or unauthorized stream scraping.


## TMDB attribution and licensing

TMDB metadata and images may be used only in accordance with the current TMDB API terms and attribution requirements. The app displays this notice:

> This product uses the TMDB API but is not endorsed or certified by TMDB.

The TMDB FAQ also requires the TMDB logo and placement of attribution in an About/Credits-type area; the approved logo must be used and must not imply endorsement. The logo asset is not yet integrated, so the production attribution checklist remains incomplete. Non-commercial use requires attribution; commercial use requires a separate licensing review/contact with TMDB. Review the current official terms before release.

Official reference: https://developer.themoviedb.org/docs/faq
